# GymLogger logo

Created using the built-in image generation tool. The source PNG is
`gym_logger_logo.png`. Platform launcher sizes are generated by
`tool/generate_icons.ps1`; adaptive Android icons add an inset for launcher masks.
The app's existing AppColors palette is unchanged.

## Generation prompt

Use case: logo-brand. Create a polished square app launcher logo for a strength-training workout log app. A single bold, distinctive geometric emblem combining a barbell and an upward progress/check gesture, instantly readable at small icon sizes. Flat vector-like graphic, crisp edges, balanced proportions, premium restrained athletic aesthetic. Use the app's existing palette: electric lime #CCFF00 emblem on a solid charcoal #121417 background. Center the complete emblem within the central 60% of the square, with generous clean background on every side so circular launcher masks cannot clip it. Full-bleed opaque square background, no rounded outside corners. No words, letters, numbers, gradients, shadows, texture, border, mockup, or watermark. Deliver one final icon, not a sheet of alternatives.
